# JUNE FORGE ⚒

Futuristic static control deck for the **..wdp → xjx** pipeline — obfuscate, version, ship.

**Live:** https://eminentboy11.github.io/june-forge/

- 100% client-side — your GitHub token never leaves your browser
- Deterministic obfuscation (javascript-obfuscator, seed 1337) → byte-identical replays
- VPS-style repo explorer with drag-drop file/zip commits
- Version registry + one-click activation of any past build
- Drift check: verifies xjx actually received the build
